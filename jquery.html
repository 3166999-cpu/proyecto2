INVESTIGACIÓN WEB · TEMA 01

JavaScript: dale vida a tu página web.

Aprende cómo funciona JavaScript y cómo permite crear páginas interactivas, responder a las acciones de los usuarios y modificar el contenido sin recargar toda la página.

01 · CONCEPTO GENERAL

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para añadir interactividad y comportamiento a las páginas web. Trabaja junto con HTML, que organiza el contenido, y CSS, que define la apariencia visual.

Con JavaScript podemos validar formularios, mostrar mensajes, crear menús interactivos, actualizar información y responder cuando una persona hace clic en un botón.

HTML

Organiza los títulos, textos, imágenes, enlaces y formularios.

CSS

Controla los colores, tamaños, espacios y diseño de la página.

JavaScript

Añade acciones, cálculos y respuestas a la interacción del usuario.

02 · CARACTERÍSTICAS

¿Qué lo hace importante?

Interactividad

Permite responder a clics, selecciones y otras acciones.

Manipulación del DOM

Puede modificar textos, imágenes y elementos HTML desde el código.

Cálculos

Realiza operaciones y actualiza totales en una aplicación web.

Validación

Ayuda a comprobar los datos introducidos en formularios.

Navegadores

Los navegadores modernos pueden ejecutar JavaScript directamente.

Integración

Puede trabajar con HTML, CSS, JSON y diferentes bibliotecas.

03 · APLICACIÓN PRÁCTICA

JavaScript en Sazón Artesana

En el sitio web de Sazón Artesana, JavaScript puede utilizarse para mostrar mensajes, calcular el importe de una compra, validar los datos de un cliente y mejorar la navegación.

Ejemplo: botón interactivo

Presiona el botón para comprobar cómo JavaScript puede responder a una acción del usuario.

Aquí aparecerá el mensaje.

Código utilizado

const boton = document.getElementById("botonMensaje");
const resultado = document.getElementById("resultadoMensaje");

boton.addEventListener("click", function () {
    resultado.textContent =
        "¡Bienvenido a Sazón Artesana! Gracias por visitarnos.";
});
Explicación:

getElementById() busca un elemento por su identificador. addEventListener() detecta el clic y textContent cambia el texto que aparece en la página.

04 · ANÁLISIS

Ventajas y consideraciones

Ventajas

  • Mejora la experiencia del usuario.
  • Permite crear páginas dinámicas.
  • Se integra con HTML y CSS.
  • Facilita validaciones y cálculos.
  • Cuenta con una amplia comunidad de desarrollo.

Consideraciones

  • Un error en el código puede impedir que una función trabaje.
  • Es importante probar la página en diferentes navegadores.
  • La validación del navegador no sustituye la validación del servidor.
  • El código del lado del cliente no debe guardar secretos ni contraseñas.
  • Se necesita mantener el código organizado y comprensible.
05 · CONCLUSIÓN

Lo que aprendimos

JavaScript es una herramienta fundamental para desarrollar sitios web interactivos. Su uso permite que una página no sea solamente informativa, sino que también pueda responder a las necesidades de sus visitantes.

En Sazón Artesana, este lenguaje puede mejorar la navegación, presentar mensajes y facilitar futuras funciones, como un formulario de pedidos o un carrito de compras.
