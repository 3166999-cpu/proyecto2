JSON: datos organizados para la web

JSON permite representar e intercambiar información de manera organizada. En SAZÓN ARTESANA podemos utilizarlo para guardar datos de nuestros platillos, precios y categorías.

Ver demostración
01 · Concepto

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar e intercambiar datos entre aplicaciones y sistemas.

Su estructura utiliza pares de clave y valor. También puede incluir objetos y listas de elementos. Aunque su nombre está relacionado con JavaScript, JSON se utiliza con muchos lenguajes de programación.

¿Para qué sirve?

  • Organizar información de productos.
  • Intercambiar datos entre aplicaciones.
  • Trabajar con respuestas de APIs.
  • Representar listas y registros.
02 · Ejemplo práctico

Un producto en formato JSON

Este ejemplo representa un platillo del menú de SAZÓN ARTESANA con su nombre, precio y categoría.

{ "nombre": "Pupusas artesanales", "precio": 3.50, "categoria": "Comida típica", "disponible": true }

Claves

Son los nombres que identifican los datos, como nombre, precio y categoria.

Valores

Son los datos asociados a cada clave: texto, números, valores booleanos, listas u otros objetos.

03 · Interactividad

Prueba cómo funciona JSON

Presiona el botón para que JavaScript lea los datos JSON y muestre la información de los productos.

[ { "nombre": "Pupusas artesanales", "precio": 3.50, "categoria": "Comida típica" }, { "nombre": "Empanadas dulces", "precio": 2.00, "categoria": "Postres" }, { "nombre": "Jugo natural", "precio": 1.50, "categoria": "Bebidas" } ]
04 · Ventajas y consideraciones

¿Por qué utilizar JSON?

Ventajas

  • Su estructura es fácil de leer.
  • Permite representar listas y objetos.
  • Funciona con distintos lenguajes.
  • Es útil para intercambiar datos.

Consideraciones

  • Las claves y los textos usan comillas dobles.
  • No se permiten comentarios dentro del JSON estándar.
  • Un formato incorrecto puede producir errores.
  • JSON por sí solo no es una base de datos.
Aplicación en SAZÓN ARTESANA: los datos JSON podrían utilizarse para organizar el menú y facilitar que JavaScript muestre los nombres, precios y categorías de los platillos.
Conclusión

Una forma sencilla de organizar datos

JSON es un formato importante en el desarrollo web porque facilita la representación y el intercambio de información. En una página como SAZÓN ARTESANA puede ayudar a mantener organizados los datos del menú y mostrarlos mediante JavaScript.
