Hosting y dominios

Para que SAZÓN ARTESANA pueda visitarse desde internet, necesita un lugar donde alojar sus archivos y una dirección que las personas puedan escribir en el navegador.

Explorar conceptos

¿Qué es Web Hosting?

El hosting o alojamiento web es un servicio que permite guardar los archivos de un sitio web en un servidor conectado a internet. Así, otras personas pueden acceder a las páginas y sus recursos.

¿Qué puede almacenar?

  • Archivos HTML y CSS.
  • Archivos JavaScript.
  • Imágenes, iconos y otros recursos.
  • Otros archivos que necesite el sitio.

¿Qué es un dominio?

Un dominio es la dirección fácil de recordar que las personas utilizan para encontrar un sitio web. Se relaciona con la dirección técnica del servidor donde se encuentra el sitio.

Ejemplo

www.sazonartesana.com

Este es un ejemplo ilustrativo de una dirección, no una confirmación de que el dominio esté registrado.

Comparación

¿Cuál es la diferencia?

Característica Hosting Dominio
Función Almacena los archivos del sitio. Sirve como dirección del sitio.
Ejemplo Espacio en un servidor web. www.ejemplo.com
¿Para qué ayuda? Permite entregar las páginas a los visitantes. Facilita encontrar el sitio en internet.

Un sitio puede utilizar un dominio propio y un servicio de hosting, aunque algunas plataformas ofrecen direcciones gratuitas sin que tengas que comprar un dominio.

Publicación del proyecto

¿Cómo publicar SAZÓN ARTESANA?

Para un proyecto escolar estático hecho con HTML, CSS y JavaScript, una opción es utilizar GitHub Pages.

1

Preparar

Guardar los archivos del sitio en una carpeta organizada.

2

Subir

Crear un repositorio en GitHub y subir los archivos.

3

Configurar

Entrar en Settings → Pages y seleccionar la rama y carpeta correctas.

4

Comprobar

Abrir el enlace publicado y probar los botones y las páginas.

Conclusión

El hosting y los dominios cumplen funciones diferentes pero complementarias. El hosting guarda los archivos del sitio, mientras que el dominio facilita encontrarlo. Para nuestro proyecto, una plataforma de alojamiento estático permite practicar la publicación de páginas web.
